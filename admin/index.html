Cloudinary 사진 업로드 설정

Cloudinary에서 확인한 두 값을 한 번 저장하면 이 브라우저에서 사진 업로드 버튼을 사용할 수 있어요.

처음 한 번 설정

  1. Cloudinary 계정을 만들고 Console에 로그인
  2. Settings → Upload → Upload presets로 이동
  3. Add upload preset을 누르고 Signing mode를 Unsigned로 설정
  4. Cloud name과 preset 이름을 위에 입력하고 저장

API Secret은 절대로 입력하거나 공개하지 마세요.
